Datenschutzerklärung – LH Assistent

Stand: November 2026

Wer nutzt die App?

LH Assistent ist eine rein private Anwendung. Sie wird ausschließlich vom Betreiber selbst mit seinem eigenen Google-Konto genutzt. Daten anderer Personen werden nicht gezielt verarbeitet.

Welche Google-Daten werden verwendet?

  • Google Kalender: Termine lesen, anlegen und ändern. Löschen nur nach ausdrücklicher Bestätigung durch den Betreiber.
  • Gmail: nur lesen (Betreff, Absender, Vorschau und bei Bedarf Text einzelner Mails), um Wichtiges zusammenzufassen. Es werden keine Mails gesendet, gelöscht oder verändert.

Wo werden die Daten verarbeitet?

Die Anwendung läuft auf einem privaten Server des Betreibers. Für die Formulierung von Antworten werden die jeweils benötigten Inhalte an den KI-Dienst Anthropic (Claude) übermittelt. Ergebnisse werden dem Betreiber über Telegram angezeigt. Darüber hinaus werden keine Daten an Dritte weitergegeben, verkauft oder für Werbung genutzt.

Speicherung

Google-Daten werden nicht dauerhaft in einer eigenen Datenbank gespeichert, sondern bei Bedarf direkt bei Google abgerufen. Technische Protokolle auf dem privaten Server werden regelmäßig gelöscht.

Google API Services User Data Policy

Die Nutzung und Übertragung von Informationen, die über Google-APIs empfangen werden, erfolgt gemäß der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Diese Webseite

Diese Seite dient nur der Beschreibung der App. Sie verwendet keine Cookies, kein Tracking und keine Formulare. Sie wird von GitHub Pages (GitHub Inc.) bereitgestellt; dabei kann GitHub technisch notwendige Zugriffsdaten wie die IP-Adresse verarbeiten.

Zugriff widerrufen

Der Zugriff kann jederzeit unter myaccount.google.com/permissions entzogen werden.
